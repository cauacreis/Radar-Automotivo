# 🚗 Radar Automotivo

Sistema de radar automotivo desenvolvido para detecção e monitoramento de veículos e objetos em tempo real.

## 📋 Sobre o Projeto

Este projeto tem como objetivo desenvolver um sistema de radar automotivo capaz de:

- Detectar obstáculos e veículos ao redor
- Monitorar distâncias em tempo real
- Emitir alertas de proximidade
- Exibir dados de forma visual e intuitiva
